# 問問小豬

塔羅、易經、雷諾曼三合一的線上占卜小網站，吉祥物是 may22 畫的粉紅小豬。

- `index.html` 首頁
- `tarot.html` 塔羅牌（78 張萊德偉特，牌面圖在 `cards/`）
- `iching.html` 易經起卦
- `lenormand.html` 雷諾曼
- `qian.html` 擲筊求籤（六十甲子籤）
- `numerology.html` 生命靈數（個人靈數、生日九宮格、流年、兩人配對）
- `stats.js` 匿名統計（寫進 Google 試算表，網址填在檔案最上面）
